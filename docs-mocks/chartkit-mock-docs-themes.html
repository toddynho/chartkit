Themes

mock-plausible Reference — preset gallery: Soft (default), refined, editorial, midnight, plus 16 importable presets from @chartkitdev/core/themes. Same 6-chart board in every preset. Prod URL: /docs/themes (extensionless). For tokens & --ck-* see Concepts · Themes & tokens.

SIZE planned · Reference

Built-in presets

Omit theme, or set "soft" / "auto", for Soft. Soft and refined/editorial use light-dark() so the page color-scheme wins. Midnight is the opt-in dark card; unknown names still resolve there.

Importable presets (16)

Register with import "@chartkitdev/core/themes" (or a single file). Then theme: "mocha" etc. resolve. Soft in docs mocks is an accent shorthand — schema Soft = built-in soft.
