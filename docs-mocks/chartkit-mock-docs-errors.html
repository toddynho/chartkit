Diagnostic shape

Mirrors jsonlint-core: stable code, severity, message, JSON Pointer path, hint, optional fix. All diagnostics return in one pass. Agents apply repair() locally — no model round-trip for most fixes.

json · diagnostic (CK2001) 
{
  "code": "CK2001",
  "severity": "error",
  "message": "field \"Revenue\" not found in data",
  "path": "/encoding/y/field",
  "hint": "available fields: month, revenue; did you mean \"revenue\"?",
  "fix": [
    { "op": "replace", "path": "/encoding/y/field", "value": "revenue" }
  ]
}

Machine indexes

Build emits /errors.json (every CK code + example pointer). Leaf pages at /docs/errors/<CKxxxx> carry message, cause, pointer example, repair patch, and the CK3012 accepted-not-applied list.

For agents

Validate → repair → render

Point at llms.txt, emit a spec, validate(). On failure, repair() applies JSON Patch locally. CK3012 warnings mean the key is accepted but not drawn yet — do not loop forever on those.
