Histogram

A JSON spec any agent can emit — beautiful by default. Binned distribution of one quantitative field. Schema shape (when present): bins encoding.x; mark.bins (default 8), mark.binWidth, or mark.bin (count, width, sturges, sqrt, fd). Optional encoding.y is a pre-binned count.

Anatomy

Three pieces agents usually touch — the quantitative field to bin, the bin rule, and the resulting bars.

  1. 1Field — quantitative encoding.x (required to bin). Plain values or a named field like ms.
  2. 2Bin rule — mark.bins (default 8), mark.binWidth, or mark.bin: count · width · sturges · sqrt · fd.
  3. 3Bars — equal-width bins; height = count (or pre-binned encoding.y). Optional count badge in the top-right corner.
