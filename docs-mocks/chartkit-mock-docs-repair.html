repair

mock-plausible Agents — step 2 of the loop: validate() → repair() → render(). Applies safe RFC 6902 JSON Patch ops from diagnostic fix fields, revalidates, repeats. Prod URL: /agents/repair (extensionless). Start at Validate.

Apply fix · Repair all

Playground diagnostics expose Apply fix (one patch) and Repair all (repair() loop). CK1001 invalid JSON has no fix — parse first. CK3012 warnings stay as accepted-not-applied.

repair()

repair(spec, data?) clones the input, collects fix ops from current errors, applies them with applyPatch, revalidates, and repeats up to a few rounds. Stops when ok, when no patch applies, or when errors stop changing. Returns RepairResult: the repaired spec, applied patches, plus the usual ok / diagnostics.

ts · repair 
import { validate, repair } from "@chartkitdev/core/validate";

const before = validate(spec);
if (!before.ok) {
  const after = repair(spec);
  // after.spec     — patched clone (input not mutated)
  // after.applied  — RFC 6902 ops that landed, in order
  // after.ok       — revalidate result
}

JSON Patch (RFC 6902)

Each diagnostic may carry fix: JsonPatchOperation[]. Agents can apply a single op (Apply fix) or run the full loop (Repair all). Ops use the same JSON Pointers as path.

replace CK2001 /encoding/y/field 
{ "op": "replace", "path": "/encoding/y/field", "value": "revenue" }
add CK1004 /a11y 
{ "op": "add", "path": "/a11y", "value": { "alt": "Monthly revenue" } }
replace CK1005 /type 
{ "op": "replace", "path": "/type", "value": "donut" }

RepairResult

Extends ValidationResult with the repaired spec and the applied patch list. Input is never mutated.

json · RepairResult 
{
  "ok": true,
  "spec": { /* patched clone */ },
  "applied": [
    { "op": "replace", "path": "/encoding/y/field", "value": "revenue" }
  ],
  "errors": [],
  "warnings": [],
  "diagnostics": []
}

Does not invent fields: only ops from diagnostic fix arrays. Paths already gone are skipped. Max rounds keep pathological loops from spinning.
