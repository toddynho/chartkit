Validate → repair → render

render() is the loop end. After validate/repair, agents draw once — no model call. Core returns an SVG string (or error SVG); adapters expose the same bytes as renderToString.

SVG · PNG · Playground hash

Ship the SVG string from render/renderToString. Playground can rasterize to PNG (2× canvas) and share via /playground#<encodeURIComponent(spec)>. Prefer validate → repair before render so agents don’t paint error SVGs.

render()

render(spec, target?) looks up spec.type in the shared registry, draws SVG, and optionally writes target.innerHTML. It does not validate and does not throw on bad input — unknown types return an error SVG (CK1010). Import @chartkitdev/core/all (or register charts) before calling.

ts · render 
import { render } from "@chartkitdev/core/all";

const svg = render(spec);       // SVG string
render(spec, el);               // also sets el.innerHTML
// Unregistered type → error SVG (CK1010), not a throw

renderToString

Adapters wrap the same core draw for SSR. Vanilla / React return the SVG string synchronously; Vue’s @chartkitdev/vue/ssr is async through vue/server-renderer. SvelteKit SSR includes the SVG from the component.

ts · ssr 
import { renderToString } from "@chartkitdev/vanilla";
const svg = renderToString(spec);          // = core render(spec)

import { renderToString } from "@chartkitdev/vue/ssr";
const html = await renderToString(spec);   // includes SVG

SVG · PNG

SVG is the source of truth from render. PNG is a client export — playground draws the SVG onto a 2× canvas and downloads chartkit.png. Agents that need pixels should keep the SVG and rasterize at the edge.

SVG source

image/svg+xml blob from the returned string. Download as chartkit.svg. Works in SSR, email, and Markdown fences.

PNG playground

Rasterize current SVG at 2× via canvas.toBlob. Fills page --bg behind the chart. Not returned by core render().

Playground hash handoff

Share and agent handoff use the URL hash — same helper as docs “Open in the playground”:

playgroundHref(spec) /playground#${encodeURIComponent(JSON.stringify(spec))}

Playground SpecEditor reads location.hash on load, JSON.parse(decodeURIComponent(...)), and fills the editor. Share writes the hash and copies the full URL. Agents can append a repaired spec and open the link for a human review.

ts · handoff 
const href = `/playground#${encodeURIComponent(JSON.stringify(spec))}`;
// SpecEditor on mount:
//   JSON.parse(decodeURIComponent(location.hash.slice(1)))

RenderResult (mock)

Core returns a string. This mock wraps it so agents can see status, format, byte size, and the playground href beside the chart.

ts · shape 
type RenderResult = {
  ok: boolean;                 // false when error SVG (CK1010 / CK1006)
  svg: string;                 // always present
  format: "svg" | "png";       // png = client raster of svg
  playgroundHref: string;      // /playground#…
  diagnostics?: Diagnostic[];  // when ok === false
};

Does not validate: call validate/repair first. render still paints an error SVG so agents get a visible failure instead of a throw.
